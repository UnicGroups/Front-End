# Front-End

A front-end web application built with HTML, JavaScript, and CSS.

## Prerequisites

- Python 3.x installed on your machine

## Getting Started

Follow these steps to run the website locally:

### 1. Open Your Terminal/Command Line

Open a command prompt or terminal on your system.

### 2. Navigate to the Project Directory

Use the `cd` command to navigate to the folder where the project files are located:

```bash
cd path/to/your/project/directory
```

**Example:**
```bash
cd "C:\Users\YourName\Documents\Front-End"
```

### 3. Start a Python HTTP Server

Run the following command to start a local web server on port 8000:

```bash
python -m http.server 8000
```

### 4. Access the Website

Open your web browser and navigate to:

```
http://localhost:8000/HomePage.html
```

## Troubleshooting

- **Port 8000 already in use?** Run `python -m http.server 3000` to use a different port, then visit `http://localhost:3000/HomePage.html`
- **Command not found?** Make sure Python is installed and added to your system PATH
- **Ensure you're in the correct project directory** before starting the server

## Project Structure

This project consists of:
- **HTML** (55.7%) - Page structure and markup
- **JavaScript** (26.7%) - Interactivity and functionality
- **CSS** (17.6%) - Styling and layout
